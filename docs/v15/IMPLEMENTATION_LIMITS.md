# V15 interpretation and limits

Implemented in this bounded slice:
- Two upright, route-aligned elevated kicker decks with forward chevrons, hazard lips and landing-edge cues. Exact graded support, player and AI takeoff/landing, reverse/side boundary handling, gate/coin elevation consistency.
- Clean ramp-airtime refill with measured duration, actual energy transfer, one-reward-per-ramp/run ledger, cooldown and run cap. Manual thruster flight/flip, solid contact, recovery and discontinuous motion invalidate the reward.
- One sparse civilian helicopter crossing and one observational police helicopter. Ground pursuit difficulty/heat controls dispatch; the helicopter itself cannot force a bust or damage the player. Roof/deck/terrain LOS can hide its beam.
- Independent main and tail rotors, physical search pod, navigation lamps, optional rotor blur; original positional rotor/turbine/wash synthesis and a positive-transfer-only landing cue.

Not implemented by this release:
- Wall/ceiling adhesion, cylindrical tunnel driving, full vertical loop or arbitrary rolled vehicle/surface camera frame from the reference clip.
- Aircraft rigid-body/aerodynamic simulation, weapon systems, physical rotorwash affecting vehicles/trees, or manufacturer-authentic sound recordings.
- Multiplayer integration, server-side economy, new coins, cars, purchases or save migration.
- A new photorealism claim. These are original game assets; native GPU frame-time, audio listening and real-device visual acceptance still require separate observation.

The source video does not establish its exact boost equation. The game uses a documented original formula and never equates the reference popup '+22' with 22 percentage points. No video frame or user photograph is a shipped asset.
