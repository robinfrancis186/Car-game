# R3 acceptance matrix

This is a release gate, not an approval record. No item becomes visually accepted merely because source tests pass.

| Surface | Required evidence | Current gate |
|---|---|---|
| Home | Four viewport screenshots; one primary hierarchy; no duplicate dock, caption/action intersection, inaccessible target or overflow | Source/controller assertions pass; actual R3 browser pixels blocked |
| Workshop | Five real upgrades, real saved coins/shortfalls, 44px targets, scroll reachability, 360 orbit and original-car view | Source/controller and geometry checks; actual CSS/WebGL gate open |
| Shop | Five coin-unlock cars; filters/sort match DOM order; inspect never buys; scenic original-car cards close to reference | Functional assertions pass; original transparent thumbnails still a reference-fidelity gap |
| Results | Correct run reason/time/rewards and reachable Retry/Help/Home at all sizes | Existing behavior preserved; actual R3 CSS gate open |
| Coastal showroom | Warm directional sunset, dark cedar/steel, believable ocean/headland, floor and car reflection depth without raster reference overlay | Original geometry/material changes; corrected offline proof inspected with explicit stylization/ocean/foliage gaps |
| Gameplay boundary | Byte-identical protected modules/assets; restores world light/environment/exposure after menus; original drive cameras | Final aggregate passes with runtime inputs unchanged; all138 protected files exact |
| User saves | No QA touching real profiles/coins; saved data remains device/origin local | Synthetic-only UI tests; no native/profile mutation |
| Release | Durable complete source backup; actual visual acceptance; explicit publication authorization | No publication authorized |

## Important distinctions
- The unchanged V16.1 Vercel screenshot is not R3 evidence.
- Earlier hosted R1 CSS evidence is not R3 evidence.
- Synthetic DOM/controller tests cannot establish browser font metrics, hit testing, GPU rendering or FPS.
- Original Blender geometry proof cannot establish exact Three.js shader output, runtime framing or mobile performance.
- The user-provided reference images remain private and absent from the delivered runtime and full source archive.
